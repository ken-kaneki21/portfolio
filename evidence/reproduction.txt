Evidence reproduction and actual source

The public portfolio repository includes experiments/README.md and the original
synthetic experiment harnesses/fixtures, plus tools/run-qwen-http.ps1. Read their
requirements and exact historical revisions; no model weights are redistributed.

Healthcare: use the merged healthcare-claims-platform docs/live-http-acceptance.md
for the separate signed-demo HTTP and independent SQL acceptance. The accepted
historical report is healthcare-acceptance.json beside this file.

Job Intelligence: use the merged job-portal docs/cached-stack-acceptance.md for
cached ingestion and controlled Temporal restart. job-acceptance.json records the
original host run; profile filtering was not a multi-account authorization test.

EvidenceWorks: use the generic source README and docs/operator_guide.md at
https://github.com/ken-kaneki21/EvidenceWorks. The sibling evidenceworks/index.html
preserves historical sanitized manifests and reports with unchanged hashes.

Qwen: qwen-http-benchmark.json is a separate real HTTP SSE workload. Client timing
and server decode rates are distinct. The scratch-ASGI result is a different model
and transport. Reproduction needs the licensed local artifacts, not a paid API.

The website itself needs no hosted backend or model. Keep its static files together.
